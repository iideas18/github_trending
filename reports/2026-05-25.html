Ghostty-based macOS terminal with vertical tabs and notifications for AI coding agents

manaflow-ai/cmux is a macOS terminal built on top of Ghostty, tailored specifically for working with AI coding agents. It adds vertical tabs and native notifications so developers running multiple long-lived agent sessions — Claude Code, Codex, Gemini, Amp, OpenCode, and others — can keep track of what each one is doing without constantly switching windows.

Technically it inherits Ghostty's high-performance, GPU-accelerated rendering while layering on workflow features that mainstream terminals don't address: per-tab status, alerts when an agent finishes or asks for input, and a UX optimized for juggling several concurrent agent threads. Written in Swift, it feels native on macOS.

It is trending because more developers now run coding agents as background workers rather than interactive REPLs, and the standard terminal experience doesn't scale to that pattern. cmux fills a clear niche for power users of agent CLIs who want a purpose-built host instead of a generic terminal emulator.
