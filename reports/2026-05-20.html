CLI proxy that reduces LLM token consumption by 60-90% on common dev commands. Single Rust binary, zero dependencies

RTK (Rust Token Killer) is a high-performance CLI proxy that sits between your AI coding agent and the shell, filtering and compressing the output of common dev commands before they're fed into the LLM context. On typical operations — ls, cat, grep, git status, git diff, pytest, cargo test, docker ps — it reports 60–90% token savings, translating to roughly an 80% overall reduction in a 30-minute Claude Code session.

It ships as a single Rust binary with no external dependencies, supports 100+ commands out of the box, and adds &lt;10ms overhead. Integrations exist for Claude Code, Copilot, Gemini CLI, Codex, Cursor, Windsurf, Cline, Kilo Code, Google Antigravity, and Hermes via simple rtk init commands and Homebrew/Cargo install paths.

RTK is trending because token costs (and context-window pressure) have become a real bottleneck for power users of agentic CLIs. Anyone running coding agents on large repos — and watching their bill or their tool-call quota — will find immediate value, with no behavior change required from the underlying agent.
