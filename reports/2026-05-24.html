magic-trace collects and displays high-resolution traces of what a process is doing

magic-trace, from Jane Street, is a profiling tool that collects and visualises high-resolution traces of what a Linux process is actually doing on the CPU. Unlike sampling profilers, it leverages Intel Processor Trace (Intel PT) to capture near-cycle-accurate execution paths, making it possible to diagnose latency spikes, tail-latency outliers, and rare pathological code paths that ordinary profilers miss.

It is built in OCaml, ships as a single binary, and produces traces viewable in the standard Perfetto/Chrome trace viewer. Engineers have used it to investigate why production systems handle some requests slowly while serving the rest fine, to inspect what a piece of code is doing in microsecond-scale windows, and as a teaching tool for understanding low-level performance.

It is trending again as performance-engineering content gains traction and as more teams rediscover Intel PT-based tools. Particularly valuable for systems engineers, latency-sensitive service operators, HFT and trading infra teams, and anyone working on x86 performance tooling.
