oh-my-pi is a terminal-native AI coding agent designed around precision editing and disciplined tool use. Instead of streaming sloppy whole-file rewrites, it uses hash-anchored edits — each change is bound to a content hash so the model can't silently clobber code that drifted since the last read — paired with an optimized tool harness that minimizes context bloat.

It bundles LSP integration, a sandboxed Python runtime, headless browser control, and a subagent framework so a single command in your shell can drive multi-step refactors, debug sessions, or research loops. The implementation is TypeScript with Rust components for the hot paths, exposed over MCP so it composes with other agent tooling.

The project is trending in the increasingly crowded "terminal AI agent" space because it takes a much more engineering-rigorous stance on safety and token efficiency than the typical wrapper. Developers frustrated with agents that thrash on large codebases are giving it a serious look.

forge is a lightweight Python framework for building self-hosted LLM agents with first-class tool-calling and multi-step workflows. It targets developers who want to run local models — via llama.cpp, Ollama, or vLLM — and need the same structured-output and agent-loop primitives that hosted providers like OpenAI offer, without the cloud dependency.

It stays intentionally minimal — no heavy dependency tree, no opinionated agent personas — so it slots into existing codebases as a library rather than a platform.

It's trending alongside the broader push toward sovereign AI: as local models get strong enough for real agent work, teams want pragmatic glue code that just works, and forge is positioned squarely in that gap.
